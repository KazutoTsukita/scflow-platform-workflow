# Changelog

All notable changes to UniScFlow releases are documented here.

## 1.0.0 - 2026-09-03

- Provide accession-based input retrieval, interpretation, and STAR-based mapping.
- Provide 25 named platform profiles: four automatic-mapping profiles and 21 recognized documented-halt profiles.
- Preserve guarded non-target, unsupported, multiplex-warning, and project-scope terminal behavior.
- Add a provenance-labelled, non-root Linux/AMD64 container with immutable version and commit tags.
- Add container verification, GitHub release automation, SBOM/provenance attestations, and Zenodo metadata.
- Add citation metadata and release documentation.
